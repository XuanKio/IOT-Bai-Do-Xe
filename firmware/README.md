# Firmware ESP32 — base

Sketch: `esp32_core/esp32_core.ino`. Đấu nối: `hardware/README.md`.
Dependencies: ESP32 Arduino core 3.3.12, PubSubClient 2.8.0, WiFiManager 2.0.17, ArduinoJson 7.4.2.
Bốn bài kiểm thử trong `firmware/tests` chạy bằng g++ theo README gốc repo.
Setup/nạp và tích hợp MQTT có backend được bổ sung ở bản 2; hướng dẫn đầy đủ ở bản 3.
